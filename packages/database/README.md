# Jupiter database

SQLite persistence for migrations, settings, ordered domain events, sanitized audit records, service health, non-secret AI metadata, conversations/messages, normalized Mission/Workflow state, Skill definitions/health/execution history, permission state, and Computer Agent action history. Migration 6 stores Skill input/output shape metadata only. Migration 7 stores permission requests, durable grants/revocations, and sanitized audit with hashed targets; session grants stay in memory. Migration 8 stores validated Computer Agent results and artifact metadata without typed text, UI-tree contents, or screenshot bytes. The package uses the Node/Electron built-in `node:sqlite` runtime and never stores credentials.

# Jupiter database

SQLite persistence for migrations, settings, ordered domain events, sanitized audit records, service health, non-secret AI metadata, conversations/messages, normalized Mission/Workflow state, Skill definitions/health/execution history, permission state, agent action history, approved file roots, and managed artifact metadata. Migration 6 stores Skill input/output shape metadata only. Migration 7 stores permission requests, durable grants/revocations, and sanitized audit with hashed targets; session grants stay in memory. Migration 8 stores validated Computer Agent results without typed text, UI-tree contents, or screenshot bytes. Migration 10 stores artifact source, exact managed path, size, SHA-256, verification, lineage/version, user-output protection, and soft-delete state. The package uses the Node/Electron built-in `node:sqlite` runtime and never stores credentials or document contents.

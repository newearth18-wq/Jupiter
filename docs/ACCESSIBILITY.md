# SET 2 accessibility and localization

- Semantic navigation, headings, forms, status regions, tabs, dialogs, and buttons are used throughout.
- `Tab`/`Shift+Tab` traverse native controls; arrow keys, Home, and End move between Settings tabs.
- Dialogs trap focus, close with Escape, and restore focus to their trigger.
- A visible-on-focus skip link moves directly to the workspace.
- Reduce Motion removes nonessential orbital and particle animation. Static and hidden avatar modes are separate persisted preferences.
- English and Thai copy change without restart. The document `lang`, Thai-capable font stack, and line height update correctly.
- The shell collapses navigation at narrow effective widths and remains vertically scrollable without horizontal overflow.
